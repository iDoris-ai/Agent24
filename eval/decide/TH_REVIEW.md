# 泰文条目复核清单

`eval/decide/` 三份评测集与 `bench/train_data/` 训练集里的泰文（含泰英混杂）条目**全部由模型撰写，尚未经母语者复核**。请母语者逐条检查并打勾：

1. **说法是否地道**：是不是泰国人真的会这么说（口语、网络用语、礼貌尾词 ครับ/ค่ะ/คะ 的用法），有没有翻译腔。
2. **标签是否成立**：`expected` / `label` 在泰语语感下是否站得住，尤其是疑问助词（ไหม / มั้ย / หรือเปล่า / ป่ะ / ใช่ไหม / หรือยัง）造成的「请求 vs 询问」区分，例如 `ri-167`（ช่วยจำ…ได้ไหมคะ，请求）与 `ri-183`（จำผมได้ไหม，询问）。
3. **是否需要补充**：发现泰语特有、但这里没覆盖的陷阱句式，直接在文末「补充建议」写下来。

有问题的条目：在行尾写明问题与建议改法；**评测集 `id` 不改号**，改写内容后在该条 `note` 里注明「母语者复核改写」。改完跑 `cd eval/decide/bench && uv run bench --check-overlap` 确认仍为 0 命中。
