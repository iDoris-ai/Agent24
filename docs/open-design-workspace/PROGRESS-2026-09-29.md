## M1 — Embedded Creative Shell

目标：不先扩展安全/恢复能力，直接复用 Open Design 的 `od daemon start --serve-web` 与 Agent24 Electron，把真实 Open Design UI 嵌入 Agent24。

### M1.1 — 现有嵌入/桌面基础地图

- [x] 核对 Open Design：已有 `od daemon start --serve-web`，可启动 daemon + Web UI 而不启动 Open Design Electron。
- [x] 核对 Open Design runtime：已有声明式 `RuntimeAgentDef` 和共享 `acp-json-rpc` engine，后续 M3 不需要新造 runtime engine。
- [x] 核对 Agent24 desktop：已有通用 `SidecarManager` / endpoint handoff / start-health-stop 状态机和测试基础，但当前没有真实 Open Design launcher/product wiring。
- [x] 核对 Agent24 host：当前只有一个 `BrowserWindow` renderer；尚未创建 Creative `WebContentsView`。
- [x] 冻结 M1 最小分解：M1.2 launcher+health；M1.3 Creative WebContentsView；M1.4 real embed smoke/closeout。

结论：M1 不需要继续扩建 workspace/security substrate。最短实现应直接在现有 desktop main process 上增加一个开发期 Open Design serve-web launcher，并把其 URL 交给 Creative WebContentsView。
