# Agent24 视觉识别系统（VI）v0.1 提案

> 状态：v0.2（2026-11-23）：主标由「昼夜环」改为「菌丝节点」（昼夜环像 iOS 指南针，David 否决）；菌丝绿只做辅助色（隐私语义 / 菌丝图形），不作第二品牌色。预览页：[`vi-preview.html`](vi-preview.html)（浏览器直接打开）。
> 本稿只定规范，不改产品代码；落地见 §9。

## 1. 依据：定位与目标

| 来源 | 事实 | 对视觉的要求 |
|---|---|---|
| README「定位」 | 24/7 个人 AI 助手的底座；daemon 常驻，外壳可换 | 表达「一直在」「安静可靠」，不表达「炫」 |
| ADR-017 / K1 LocalOnly | 隐私优先，默认本地，云端补位默认关 | 「本地 / 外发」必须在界面上一眼可辨 |
| ADR-037 | agentd 是本体，桌面 / TUI / 移动 / Pet0 都是客户端 | VI 不能只为一个壳设计：要能落到终端字符、像素桌宠、移动瘦壳 |
| ADR-003 | 「为个人服务，以社区为协作单位」；Hyphae 菌丝网络 | 品牌母体 MushroomDAO / Mycelium 的血缘要看得见，但不喧宾夺主 |
| ADR-036 等 | 目标用户以 Apple Silicon Mac 用户为主，含开发者 | 尊重 macOS 原生质感；开发者能读懂的精确感 |
| 现有资产 | 暗底 + 琥珀黄 `#e8c547`；iDoris 像素少女形象 | 延续，不推翻：老用户零认知成本 |

**品牌一句话**：Agent24 —— 一直在你身边、只听你的、本地运行的 AI 伙伴。
**英文**：Always on. Always yours.

**目标**：
1. 让用户感到「可托付」：常驻后台的东西必须看起来稳。
2. 让「隐私状态」成为视觉语言的一部分，而不是藏在设置里。
3. 一套 token 跨 Electron / Tauri / TUI / 移动通用。

## 2. 品牌性格

| 是 | 不是 |
|---|---|
| 守夜人：安静、在场、可靠 | 科幻炫光、霓虹紫渐变 |
| 精确：数字、状态、出处说得清 | 卖萌过度、模糊的「AI 魔法」 |
| 温暖：一盏灯，不是一块屏 | 冷冰冰的企业蓝 |
| 有机：菌丝般生长、连接 | 机械齿轮、机器人头像 |

核心隐喻：**守夜的灯（Night Lamp）**——夜里一直亮着的那盏琥珀色小灯。它同时对应 24 小时、常驻、温暖、可见的状态指示。

## 3. 标志

### 3.1 主标「菌丝节点」
- 琥珀核心 = 你本机的 Agent（本体，一直在）；核心里写「24」= 全天候。
- 三条菌丝连到三个节点 = 它的外壳（桌面、手机、终端）和其他 Agent（Hyphae 通信）。呼应母品牌 Mycelium 的菌丝意象，可延伸成 Hyphae 网络图形（§6）。
- 核心带一圈很淡的琥珀光晕（只在 App 图标上），对应「守夜的灯」。
- 文字标：`Agent24`，「24」使用等宽数字字形，与 Agent 同字重，不加粗不变色。
- 历史：v0.1 的「昼夜环」（24 段刻度表盘）看起来像指南针 / 钟表，已废弃。

### 3.2 变体
| 变体 | 用途 |
|---|---|
| App 图标（核心带「24」） | Dock、Finder、关于页；64px 及以上 |
| 小尺寸版（不带数字，线和节点加粗） | 32px 及以下的 App 图标、侧栏主标、favicon：数字在这个尺寸会糊 |
| 横版组合（主标 + 字标） | 官网、README 头图、安装器 |
| 托盘模板图（单色） | macOS 菜单栏，用 Template Image 跟随系统明暗；核心 + 三条菌丝 + 三个节点，不带数字 |
| 像素版（16×16 / 32×32） | Pet0、TUI 启动画面、像素风场景 |
| 字符版 `( • )` | TUI / CLI 纯文本 |

### 3.3 规则
- 安全区：四周留出主标宽度的 1/4。最小尺寸：主标 16px，横版 96px 宽。
- 禁止：增减菌丝或节点数、把节点也涂成琥珀色（琥珀只有核心一处）、在小尺寸版里塞数字、拉伸、改成蘑菇形状（蘑菇是 MushroomDAO 的标，见 TRADEMARK）。

### 3.4 iDoris 角色
iDoris 像素少女保留为**角色（mascot）**，不是 logo。用于：欢迎页、空状态、Pet0、主动提醒。Logo 负责「可靠」，角色负责「亲近」，两者不互相替代。

## 4. 色彩

### 4.1 品牌色
| 名称 | HEX | 用途 |
|---|---|---|
| 守夜琥珀 Lamp Amber | `#E8C547` | 主强调、主标核心、主按钮、焦点（沿用现值） |
| 琥珀深 Amber Deep | `#B89A10` | 浅色模式下的强调色（沿用现值，保证对比度） |
| 夜墨 Night Ink | `#0A0A0A` | 深色背景（默认） |
| 纸白 Paper | `#F4F4EF` | 浅色背景，带一点暖 |
| 菌丝绿 Hyphae Green | `#7FB77E` | 「本地 / 私有 / 在本机」状态专用 |

### 4.2 隐私语义色（本 VI 的关键）
| 状态 | 色 | 图标 | 说明 |
|---|---|---|---|
| 本地处理 LocalOnly | 菌丝绿 `#7FB77E` | 实心圆点 | 数据没离开这台机器 |
| 发往远端 Remote | 天青 `#6FA8DC` | 外向箭头 | 用到了远程模型或网络 |
| 等待你审批 Approval | 守夜琥珀 `#E8C547` | 半环 | 需要用户确认 |
| 被拒 / 失败 | 砖红 `#E07A6A`（沿用 main 的 `--danger`） | 斜杠圆 | fail-closed |

规则：**任何「数据外发」都必须用天青 + 箭头标出**，不可只靠颜色（色弱友好）。

浅色模式加深以保证文字对比度：本地 `#3F7F45` · 远端 `#2F6FA8` · 拒绝 `#B74436` · 待确认用 `#B89A10`。

CSS token：`--local` `--remote` `--approve`，拒绝用既有的 `--danger`。`--success` / `--warning` 是通用成败提示，沿用 main 的值，与隐私语义分开：「本地」只用 `--local`。

### 4.3 中性色（深 / 浅）
以 `apps/desktop/src/renderer/styles.css` 现值为准（main 已有一套暖灰阶：`bg / surface / surface2 / border / border-strong / border-stronger / text / muted / weak`），VI 不另定。

比例：中性 85% · 琥珀 ≤10% · 语义色 ≤5%。琥珀稀缺才有「灯」的效果。

## 5. 字体
| 角色 | 字体 | 说明 |
|---|---|---|
| 界面 | 系统字体：SF Pro / PingFang SC / Segoe UI | 原生质感，零下载 |
| 数字与代码 | SF Mono / JetBrains Mono / Menlo | 时间、token、延迟、ID 一律等宽 + tabular-nums |
| 品牌标题（可选） | Inter Display 600 | 仅官网 / 发布物 |

字号阶：12 / 13 / 15 / 17 / 22 / 28 / 36。正文 13–15，行高 1.55。中文不用斜体。

## 6. 图形语言
- **刻度**：24 等分短线，用作进度、时间轴、加载（替代转圈 spinner：一格一格点亮）。
- **菌丝线**：1px 有机曲线连接节点，只用于 Hyphae 通信、记忆关联、知识图谱。
- **像素**：只服务 iDoris 与 Pet0，不进入功能界面的图标。
- 图标：线性 1.5px 描边、圆角端点、24px 网格（Lucide 风格即可）。
- 圆角：控件 8px、卡片 12px、弹层 14px。阴影只在浅色模式用，深色模式用 1px 边框表达层级。

## 7. 动效
- 「呼吸」：常驻状态点 4s 周期缓慢明暗（opacity 0.55↔1），表示 daemon 活着；暂停 = 静止。
- 时长：微交互 120ms，面板 220ms，`ease-out`。遵守系统「减少动态效果」。
- 禁止：弹跳、闪烁、彩虹渐变。

## 8. 语气（与视觉配套）
- 说事实，不说「魔法」：「已在本机完成，未联网」优于「AI 帮你搞定啦！」。
- 状态带出处：模型名、本地 / 远端、耗时。
- 中英并列时中文在前。
