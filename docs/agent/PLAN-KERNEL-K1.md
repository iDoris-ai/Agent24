### 既有法律与边界

- 必须符合 [`APPROVAL.md`](../laws/APPROVAL.md) L-APPR-1..7：风险判断不能放宽用户权限；批准仍走统一门禁；`External` 不提供宽泛 session grant；常驻授权按确切目标收窄；读权限不上存储。模块声明和第一方签名不构成宿主授权。
- 必须符合 [`MEMORY.md`](../laws/MEMORY.md) L-MEM-1..7：不得向模块暴露原始 store、调用方不得自报 owner/scope、不得夸大隔离保证。新数据流标记须内核注入，不给模块任意改写授权身份的字段。
- 必须符合 [`CONTEXT.md`](../laws/CONTEXT.md) L-CTX-1..4：会进入上下文的数据来源应可点名、可审计；运行记录不是完成证据。
- K1 ADR 若确立新的长期隐私/外传不变量，先提议独立新增 `docs/laws/PRIVACY.md`（或获批的合并位置），按 laws README 单独闭环；不得在实现 PR 中顺手改法律。
- 安全模式不是 `has_remote()` 的永久替代品，也不以 `output_privacy: local_only` 自声明允许网络访问。早期可以保留 #733 D8 的保守限制，直到逐 run 的执行保护、反例测试和真实产品路径验收均通过。

## 2. ADR 与 jason 拍板点

ADR 先行，按以下顺序分别审议；每份 ADR 明确威胁模型、状态/迁移、兼容性、否决路径、反例测试和法律映射。**四份 ADR 及后续所有权限、隐私、协议实现均为高风险，PR 必须等待 PR-Daemon APPROVE 后才可合入 `ab/kernel`。** ADR 提案不能自行授权实现。

1. **ADR-K1-01 通用模块工具契约**：manifest 声明与宿主授权交集；工具身份/命名空间/发现和生命周期；可信 run/session/tool-call/resource 上下文注入；有限响应体、结构化错误、超时、取消、幂等边界、不自动重试；停用/熔断/不可用过滤与类型化失败。不得把第三方风险声明当权威。
2. **ADR-K1-02 会话数据流与安全模式**：来源/修订/模式标记如何进入对话并跨轮次、重启/恢复、委派、模型路由、HTTP/MCP/模块/Exec、记忆和后台任务传播；LocalOnly fail-closed；获准云处理的资料范围、用途、目的地、有效期、撤销和更严格政策优先级；`has_remote()` 何时可退役。与 C5 A-3、ID-1/3 对齐。
3. **ADR-K1-03 启用授权与信任**：逐工具可读/可改/可外发范围、风险由宿主定级、明确同意、期限、撤回即时生效；第一方默认安装启用与开发阶段手动安装区分；升级/签名/来源验证能证明什么、不能证明什么。与 OD-M11 capability 路线明确接口关系，不以其暂停任务为隐含前置。
4. **ADR-K1-04 审计与共同授权**：模块调用成功/失败/拒绝的最小关联审计（不记正文、凭据或完整敏感提示）；哈希链字段与保留边界；UI 与 Agent 的身份、资源、业务操作共用权威；页面/模块自己的日志不是内核审计。依赖 C1 K-2。

**须由 jason 拍板，ADR 草案不得擅定：**

- 安全模式名称、默认策略及何时向用户暴露；LocalOnly 是否为文档/敏感来源默认值；是否提供获准云模式的首发产品承诺。
- 云授权粒度（逐次/资料×用途×目的地）、是否允许持久授权、有效期与撤销语义；组织/来源的更严限制如何表达。
- 第一方默认启用边界与第三方/手动安装的默认风险；升级后是否重新同意及签名信任根策略。
- 审计字段、保留期、用户查看/导出/删除边界，以及 UI 和 Agent 共同授权入口的产品归属。
- `has_remote()` 保守兼容期的退出门槛，以及 K1 与仍 PAUSED 的 OD-M11/F11.0 是否共享交付或只共享契约。

## 5. 验收判据

- 模块工具只在模块启用、能力有效且宿主授权交集非空时通告；停用/熔断、操作不可用、未知风险声明不造成越权。成功、类型化失败、拒绝、超时、取消可关联；取消/重试不会重复副作用。
- LocalOnly 时远端即使已配置，也不得收到资料；禁止通过 HTTP/MCP、其他模块、Exec、续轮/恢复/委派、`remember_exchange`、缓存和后台任务外传。执行层不能证明符合所选模式时明确阻断/报 unavailable。
- 获准云处理只发送明确授权的数据、用途和目的地；用户拒绝、撤销、过期、模式切换或来源更严限制立即阻断。拒绝不是同意，切换不追溯放大许可，已发内容不宣称可收回。
- 未确认的模块工具逐次审批；确认后仍受风险、资源与数据政策门控；撤销立即生效。第一方默认安装只影响安装体验，不提升工具风险或绕过授权。
- 审计记录调用 id、actor、操作和结果码，不记录正文、凭据或完整敏感提示；业务 UI 与 Agent 由同一内核授权身份/资源/动作，不接受模块日志冒充内核记录。
- #708 记录真实 macOS 产品路径证据并区分组件、接线、验收和发行。法律变更必须单独 PR；实现 PR 点名符合的 L-APPR、L-MEM、L-CTX 及新增隐私法律。
