# Showcase 下载维护：Design 用户可控下载

来源：用户 2026-10-14 明确反馈 Design 组件下载慢，且没有取消/恢复界面，只能等待。
范围：`ab/showcase-download`，基于主线 `eb7f546f505de5bc7e368436e0426aaee8b73def`；不启动 M3/Workspace 等暂停里程碑。

## SD-01（本轮唯一代码任务）
- Design 下载页面新增停止当前下载、保留进度、显式继续，退出/断网后仍可恢复。
- 不把暂停或下载中的文件当成安装成功；保留既有已安装版本。
- 显示实际传输速度、合理剩余时间或“等待网络”；标明正确的 MiB 单位。
- 部分文件必须绑定当前 manifest 的 URL/版本/SHA/总字节数，不能猜测并采用旧随机 partial 的来源。
- Range 206 验证起点/总数；200 安全从头；416 有界处理；最终仍完整 SHA、大小、资源合同校验后原子发布。
- 保留既有重定向 allowlist、文件/symlink 防护、空闲超时、单 job 并发保护。
- 打开页面或重新启动不自动下载；继续由用户点击，不能自动消费此前取消授权。

验收：先以 UI 缺失与真实 HTTP fixture 证明 RED，再验证暂停/重启续传、206/200/416、损坏 prefix、不同 manifest、不合法链接、取消并发、最终不留错误安装标记及原有全部安全测试。

测试只用临时目录与本地 HTTP；不调用真实模型、麦克风、用户配置或付费 API。
默认 ≤300 生产行；安全不可拆超出时报告给 Parent，未经决定不得扩大。测试/文档不计入生产行数。
