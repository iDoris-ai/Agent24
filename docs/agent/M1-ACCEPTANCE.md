# M1 真机验收清单（记忆即产品）

> 在笔记本上用 `ab/m1-memory` 的 `pnpm dev`（真实 agent24d + 桌面端 + 本地模型）逐条执行；每条记录「通过 / 失败 + 现象」。
> 全部通过后才开 release PR `ab/m1-memory → main`。

## 0. 准备
- [ ] `git switch ab/m1-memory && git pull`；`pnpm install --frozen-lockfile`；`pnpm dev` 启动，左侧出现「记忆」页
- [ ] 记忆页显示空状态「说『记住……』让我记住」，「暂停记忆」开关为未暂停

## 1. 记住（T06）
- [ ] 会话 A 发：「记住我对花生过敏」→ 模型回复正常
- [ ] 记忆页出现该条：原句、来源会话、记录时间正确

## 2. 重启后跨会话召回（T05 / T07 / T07.1）
- [ ] 完全退出 Agent24（含 agent24d），重新 `pnpm dev`
- [ ] 新建会话 B 问：「我对什么过敏？」→ 回答提到花生
- [ ] 会话 B 问一个无关问题（如「how to write a for loop in python」「解释一下量子计算」）→ 回答中不出现花生（无误注入，T07.2）

## 3. 撤回（T09 / T10 / T11）
- [ ] 记忆页对该条点「撤回」→ 二次确认文案为「撤回后不会再在新会话中被想起；原始对话仍保留在本机」→ 确认后条目消失
- [ ] 新建会话 C 问：「我对什么过敏？」→ 不再提到花生
- [ ] 再说一次「记住我对花生过敏」→ 记忆页重新出现（撤回后可重新记住）

## 4. 暂停记忆（T10 / T11）
- [ ] 打开「暂停记忆」→ 开关显示已暂停；新会话说「记住我喜欢喝茶」→ 模型明确告知记忆已暂停、本条不会被记住；记忆页无新条目
- [ ] 暂停状态下问「我对什么过敏？」→ 不召回
- [ ] 重启 Agent24 → 开关仍为已暂停
- [ ] 关闭暂停 → 召回恢复

## 5. 审批中重启（T07.1 修复）
- [ ] 会话里发起一个需要审批的工具操作，审批弹出时退出 Agent24；重启后批准 → 运行继续，回答仍能引用此前对话内容
