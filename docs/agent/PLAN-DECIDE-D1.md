# D1 — 记住意图与召回门控接入

> 基于 `PLAN-DECIDE.md` D1、`DECISION-MODELS.md` §10（D0-8）及 #688 评审 L1–L4。
> 决策接口须同时支持中文、英文、泰文。任务按可独立评审的 task PR 拆分；每个 PR ≤300 行。

## 已定方案

- 快速层使用五档方案 B：8GB `e5-small`；16GB `e5-base`；24GB `e5-large-instruct`；32GB `Qwen3-Embedding-4B`；64GB+ `Qwen3-Embedding-8B`。64GB+ 可选 `kev-4b` 深度层。
- 必须能切换到方案 A（五档分别用 Qwen3-Embedding 0.6B / 0.6B / 4B / 4B / 8B）。切换只更换模型目录和重训分类头；请求、响应、分类头输入输出与调用点接口保持不变。
- 模型和运行时按需下载，模型文件不进仓库；目录固定 revision、sha256、许可证和实测资源数据。未同意下载、离线或组件不可用时按现有 `unavailable` 语义处理，不静默换模型。
- 三档阈值按决策点显式配置：高于执行阈值才给出建议动作；中间带不写入/不注入并按点反问或弃权；低于升级阈值交给人或维持确定性安全路径。不得有全局默认值。Recall 的 `need` 只有过执行阈值才允许尝试召回，最终结果仍受 owner/active 等 A 类硬过滤约束。
- 规则是高精度地板；模型不得覆盖明确的规则拒绝、撤回或安全约束。T0（未同意、离线等）对既有规则行为保持逐字节兼容。
- D1 覆盖 `retain.intent` 与 `recall.gate`，接通本地决策日志及澄清/撤回标签回流。日志仅本地保存，并遵从既有可导出、删除及保留期契约。

## 真机验收清单（jason）

每种语言各跑完以下六类；记录原句、模型档、规则/模型输出、置信度、最终动作和日志 ID。泰文样例先由母语者确认。记忆写入测试使用可撤销的无敏感测试事实。

| 场景 | 中文 | English | ไทย |
|---|---|---|---|
| 记住 | 记住，我对花生过敏。 | Remember that I’m allergic to peanuts. | จำไว้ว่าฉันแพ้ถั่วลิสง |
| 问句陷阱 | 你记住我叫什么了吗？ | Do you remember what my name is? | คุณจำได้ไหมว่าฉันชื่ออะไร |
| A-不-A | 你记不记得我说过的过敏信息？ | Do you or don’t you remember my allergy? | คุณจำเรื่องอาการแพ้ของฉันได้หรือเปล่า |
| 撤回 | 刚才那条别记了，请删掉。 | Forget what I just asked you to remember; delete it. | ลืมเรื่องที่เพิ่งให้จำ แล้วลบออกด้วย |
| 低置信反问 | 这个以后可能有用吧。 | This might be useful later, I guess. | เรื่องนี้อาจมีประโยชน์ทีหลังมั้ง |
| 无关不注入 | 写一首关于月亮的诗。 | Write a poem about the moon. | แต่งกลอนเกี่ยวกับดวงจันทร์ |

### D1 全局验收门

- 三语分别报告 precision/recall、误写入率、无关误注入数、校准与 P50/P95；误写入率不得高于规则基线，`recall.gate` 无关误注入必须为 0。
- CPU P95 <100ms；T0 输出与旧规则实现逐字节相同；不可用后端不得伪装为模型结论。
- 日志能反映实际执行的每一层、模型版本、概率、耗时、阈值动作和硬件档；撤回与澄清回答可回流为标签。
- 任一记忆数据写入、日志 schema 或下载/协议改动，先得到 PR-Daemon `APPROVE` 再进入对应高风险 task PR。
