## 附：刷新探针（只读）

```sh
gh release list --repo iDoris-ai/Agent24 --limit 10
git fetch --no-prune origin '+refs/heads/*:refs/remotes/origin/*'
for b in memory-p1 kernel documenting weknora office-assistant idoris decide comm maint; do
  git rev-list --merges --first-parent --count --since=<上次发布日> origin/main..origin/ab/$b; done
gh pr list --repo iDoris-ai/Agent24 --state open --json number,baseRefName,title,reviewDecision
git log --merges --first-parent --format='%h %cs %s' -30 origin/main
```

不要用「领先 main N 个提交」作口径：K1 是 squash 合并，这个数会严重失真。改用「上次发布以来的合并数」。
