# Sin90 四象限与复盘闭环
范围：只加排序视图和完成证据，不重写方向、节奏、任务状态机。不自动排满时间，不新增待办库。
1. Sin90 提供按 task_id 关联的优先级（AI 判断/依据、人工覆盖分开），用户评估建议和完成备注；AI 读取活动方向、节奏、当前未完成任务。证据不足显示未评估。AI 不可覆盖人的决定。
2. Agent24 保持方向/节奏原功能，在当日工作展示彩色+文字四象限，切换长期不丢上下文；展示真实未评估状态。完成不依赖备注或 AI，可补记。对旧模块正常降级。
3. 完成事件是唯一事实，不复制任务。本周复盘引用完成证据、备注及当时分类；无备注不臆测成效，变更下周计划必须走确认提案。
4. 验收：人工改判→重新评估仍保留；完成无备注→补记→本周素材仅一条→周复盘→接受建议才改变计划。测试用独立临时数据，验证旧模块。不得修改 main、发版、伪造 pin。
